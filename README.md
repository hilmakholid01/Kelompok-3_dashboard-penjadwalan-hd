# Dashboard Penjadwalan Hemodialisis (HD)

Prototype tugas untuk dashboard penjadwalan hemodialisis dengan:
- 20 pasien sintetis
- 8 mesin HD
- Sesi pagi dan siang
- Ringkasan statistik
- Tabel jadwal
- Filter nama/No. RM, sesi, dan status
- Peringatan otomatis
- Status mesin

## Cara menjalankan
1. Ekstrak folder.
2. Buka `index.html` di browser.
3. Tidak membutuhkan XAMPP, PHP, atau database.

## Deployment
### GitHub
Buat repository baru, misalnya `dashboard-penjadwalan-hd`, lalu upload:
- index.html
- style.css
- script.js
- README.md

### Netlify
Bisa menggunakan Netlify Drop dengan menyeret folder project ke area upload. Atau hubungkan repository GitHub ke Netlify.

## Catatan
Data pasien seluruhnya fiktif/sintetis dan hanya untuk pembelajaran. Jangan memasukkan data pasien nyata.
